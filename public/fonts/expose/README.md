# Expose font setup

This project is wired to use the licensed Expose webfont supplied separately by the project owner.

Copy these four files from `Expose_Complete/Fonts/WEB/fonts/` into this folder:

- `Expose-Regular.woff2`
- `Expose-Medium.woff2`
- `Expose-Bold.woff2`
- `Expose-Black.woff2`

Font binaries are intentionally not stored in this generated project archive.
