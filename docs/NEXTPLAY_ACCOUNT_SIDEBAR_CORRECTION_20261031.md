# NextPlay Sportswear - My Account navigation and panel typography correction

## Scope

Corrects the user-visible My Account sidebar introduced by the prior typography update, on every customer-account route that reuses `x-storefront.account.frame` / `x-storefront.account.sidebar`. No backend, database, route, form, checkout or auth logic changes.

### Fixed

- Restored **compact navigation** using centralized `--nps-small` (14px, Expose) with 40px minimum rows. The prior 15px / 44px styling was too spacious in the narrow sidebar.
- Restored the selected link's **white-on-navy contrast**; the prior orange-on-navy text was poorly readable.
- Nonselected hovered links use the soft neutral background and central link color. Only the actual current-route link has a navy background.
- Identity name and email use the central small/caption scale, and Logout uses the compact sidebar sizing while the page's main buttons retain 48px minimum controls.
- Inner account panels, summary sections, and form section titles use the centralized H3 token instead of a page-level H2; compact order-list and artwork-list headings use H4. The outer page title retains the H1 template.
- Mobile contextual H3 override prevents inflated headings in nested cards.

## Files changed

1. `resources/css/storefront-typography.css` (authoritative scoped rules)
2. `public/css/storefront-typography.css` (regenerated by `deploy/build-storefront-typography.py`)
3. `resources/views/components/layouts/storefront.blade.php` (stylesheet cache identifier only)
4. This note.

## Protected

Unmodified: `resources/views/components/storefront/account/sidebar.blade.php`, customer account route handlers, product listing-card components, all category/product filter components, `resources/css/storefront.css`, `resources/css/storefront-theme.css`.
