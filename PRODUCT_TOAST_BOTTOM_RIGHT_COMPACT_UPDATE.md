# Product toast bottom-right compact update

The storefront customization and cart notification has been resized and repositioned.

## Changes

- Toast stack is fixed to the bottom-right corner.
- Desktop width is capped at 330px.
- Mobile width is capped at 320px and respects safe-area insets.
- Icon, text, close control, padding, shadow, and progress bar were reduced.
- Entry animation now comes from the lower-right direction.
- Existing accessibility, auto-dismiss, stacking, and notification events are unchanged.

## Main file

- `resources/css/storefront.css`
