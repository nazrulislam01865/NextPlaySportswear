# Product visitor label and review layout update

- Product-card visitor copy now reads `1 shopper visited this week` or `N shoppers visited this week`.
- The same copy is returned to the product-details activity badge.
- Product-detail review presentation now follows the supplied five-panel reference layout: overall score, rating breakdown, and up to three genuine written reviews.
- Missing rating-breakdown data is shown with neutral dashes instead of fabricated counts.
- Written review cards and verified-buyer badges still render only from genuine product review data.
